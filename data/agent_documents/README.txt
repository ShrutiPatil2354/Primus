Sample agent documents
======================

These text files are self-contained sample knowledge bases for the PRIMUS
agent workspace. They contain factual rules, procedures, reference values,
and explicit boundaries. Upload each file to the matching agent from Build
Your Agent. Ask questions covered by the document to verify an answer, then
ask an unrelated question to verify that the agent says the knowledge is not
available instead of guessing.

Existing agents:
- HR Bot: hr_employee_handbook.txt
- Legal Advisor: legal_contract_review_policy.txt
- Finance Agent: finance_month_end_close.txt
- Medical assistant: medical_triage_guide.txt

New agents:
- Travel Planner: travel_planning_preferences.txt
- Study Coach: study_coaching_playbook.txt
- Home Maintenance Guide: home_maintenance_safety.txt

The agent_creation_templates.txt file contains the matching creation fields,
upload mapping, and suggested in-scope/out-of-scope test questions. It is a
setup guide, not an agent knowledge base.
