# Contributing to PRIMUS

1. Fork the repo and create a branch: `git checkout -b feature/your-feature`
2. Keep the zero-prior rule: **no hardcoded task knowledge** anywhere in code.
3. All new knowledge must enter through the memory cortex (`src/core/memory.py`).
4. Test locally: `python app.py` and run the zero-prior demo script from README.
5. Commit with clear messages and open a Pull Request.

Code style: Python PEP8; C++17 modern style.
